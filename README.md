# PT-boundary-control

> **Repository:** https://github.com/hanzhiji/PT-boundary-control  
> **Manuscript:** *Prescribed-Time Contracting-Boundary Control of a Tendon-Driven Flexible Arm*

This repository hosts the supplementary materials accompanying the manuscript **"Prescribed-Time Contracting-Boundary Control of a Tendon-Driven Flexible Arm" (BI-2026-3)**. The materials provide detailed theoretical derivations, numerical evaluation methods, visual-feedback implementation methods, and comprehensive numerical and experimental data.
